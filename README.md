# MusikAralan

A Choir Learning Management System designed to support music ministry learning and coordination.

## Technology Stack

- React
- TypeScript
- Vite
- Tailwind CSS
- Firebase Authentication
- Cloud Firestore

## Features

- Student, teacher, and admin dashboards
- Account registration and approval workflow
- Music-learning activities and piano quiz
- Learning materials and assessments
- Announcements and support chatbot

## Requirements

- Node.js
- npm
- A configured Firebase project

## Installation

Clone the repository, then enter the project folder:

```bash
cd MusikAralan
npm install
```

Configure the required Firebase settings, then run:

```bash
npm run dev
```

## Production Build

```bash
npm run build
```

## Security

Do not commit private credentials, service-account keys, or secret environment files.

Configure Firebase Authentication and Firestore security rules before deployment.
